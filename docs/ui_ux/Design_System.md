# Design System (AI Travel Planner)

## 1. Color Palette

### Primary Colors
- **Primary Brand**: `#4F46E5` (Indigo 600) - Used for primary buttons, active states, and highlights.
- **Primary Hover**: `#4338CA` (Indigo 700)
- **Secondary Brand**: `#0EA5E9` (Light Blue 500) - Used for accents, badges, and secondary elements.

### Neutral Colors (Text & Backgrounds)
- **Background (Light)**: `#F9FAFB` (Gray 50)
- **Surface (Light)**: `#FFFFFF` (White)
- **Text (Primary)**: `#111827` (Gray 900)
- **Text (Secondary)**: `#4B5563` (Gray 600)
- **Border**: `#E5E7EB` (Gray 200)

### Semantic Colors
- **Success**: `#10B981` (Emerald 500)
- **Warning**: `#F59E0B` (Amber 500)
- **Error**: `#EF4444` (Red 500)

## 2. Typography
**Font Family**: `Inter`, sans-serif
- **H1 (Display)**: 48px, Bold (700), Line height 1.2
- **H2 (Title)**: 36px, Semi-Bold (600), Line height 1.3
- **H3 (Section Title)**: 24px, Semi-Bold (600), Line height 1.4
- **Body Large**: 18px, Regular (400), Line height 1.5
- **Body Base**: 16px, Regular (400), Line height 1.5
- **Small Text**: 14px, Regular (400), Line height 1.5

## 3. Spacing & Grid
- Base unit: `4px`
- **Spacing Scale**: 4, 8, 12, 16, 24, 32, 48, 64, 96 (px)
- **Grid Layout**: 12-column grid. Max container width `1280px`. Gutter `24px`.

## 4. Components & Shadows
### Shadows
- **Card Shadow**: `0 4px 6px -1px rgba(0, 0, 0, 0.1)` (Used on white surface cards)
- **Dropdown/Modal Shadow**: `0 10px 15px -3px rgba(0, 0, 0, 0.1)`
### Border Radius
- **Buttons**: `6px`
- **Cards & Modals**: `12px`
- **Pills/Badges**: `9999px` (Fully rounded)
