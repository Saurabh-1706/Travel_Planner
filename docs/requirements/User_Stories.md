# User Stories

## Authentication & User Management
- **US1.1**: As a user, I want to sign up using my Google account so that I don't have to remember another password.
- **US1.2**: As a user, I want to fill out a travel preference profile so that the AI can suggest better destinations.

## AI Trip Planner
- **US2.1**: As a user, I want to input my budget, dates, and interests so that the AI can generate a complete itinerary.
- **US2.2**: As a user, I want to drag and drop activities in my itinerary so that I can easily adjust my daily schedule.
- **US2.3**: As a user, I want to chat with an AI assistant to get real-time recommendations for nearby restaurants.

## Booking Modules
- **US3.1**: As a user, I want to search for round-trip flights and sort them by price or duration.
- **US3.2**: As a user, I want to see hotel locations on a map before booking so I know how close they are to the city center.
- **US3.3**: As a user, I want to book a museum ticket directly through the app to avoid long queues.

## Collaboration
- **US4.1**: As a group organizer, I want to invite my friends via a link so they can view and edit our trip itinerary.
- **US4.2**: As a group member, I want to upvote or downvote suggested activities so we can decide as a group what to do.
- **US4.3**: As a user, I want to log group expenses so the app can calculate who owes whom at the end of the trip.

## Utilities
- **US5.1**: As a user, I want to download my itinerary and map for offline use in case I don't have internet access abroad.
- **US5.2**: As a user, I want to receive a notification if my flight is delayed so I can adjust my travel plans.
- **US5.3**: As a user, I want to store a digital copy of my travel insurance securely within the app.
